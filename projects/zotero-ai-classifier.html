Zotero-AI-Classifier

基于大语言模型的 Zotero 文献智能分类插件

首页 项目

简介

Zotero-AI-Classifier 是一个用于科研文献管理的 Zotero 插件。它读取文献标题、摘要和关键词， 将这些信息与用户设定的分类目录一起发送给兼容 OpenAI API 格式的大语言模型，自动判断文献应归入的目录。

这个项目重点不是单纯调用 AI，而是把分类提示词、置信度阈值、任务中止、日志记录和本地配置管理整合成可用的科研工作流。

核心功能

  • 智能归类：根据标题、摘要和关键词自动选择最合适的分类路径。
  • 置信度阈值：只有高于用户设定阈值的结果才自动移动文献，降低误分类风险。
  • 结构保存与恢复：支持备份和恢复 Zotero 收藏夹结构。
  • 数据导出：可将标题、摘要和关键词导出为 JSON，便于后续分析或让 AI 推荐分类层级。
  • TXT 层级导入：从文本文件批量创建文献分类目录。
  • 隐私优先：API Key 存储在本地配置文件中，不经过额外服务器转发。

实现思路

  • 通过 Zotero API 获取文献标题、摘要和关键词。
  • 将文献信息和用户的分类目录结构组合成 Prompt。
  • 调用兼容 OpenAI API 格式的 LLM 服务，要求返回分类路径、置信度和理由。
  • 解析返回 JSON，并根据置信度阈值决定是否移动文献。
  • 分类过程串行处理，降低 API 限流风险；单篇失败不影响后续任务。
